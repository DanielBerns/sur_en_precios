Flujo de Sincronización UNPSJB

El procesamiento y transformación de datos diarios del SEPA se realiza de forma desacoplada para optimizar los recursos del servidor web:

  • Extracción y ETL en UNPSJB: La descarga de archivos masivos, descompresión, limpieza taxonómica y cálculo de precios de referencia se ejecutan en un servidor dedicado en la Universidad Nacional de la Patagonia San Juan Bosco.
  • Carga hacia Producción: El archivo public.sqlite optimizado e indexado se carga periódicamente hacia este host.
  • Persistencia Total de Usuarios: La base de datos de usuarios y canastas (user_data.sqlite) se mantiene completamente independiente mediante códigos EAN, asegurando cero pérdida de datos ante cada actualización.
